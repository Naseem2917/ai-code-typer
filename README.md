## 🎯 What is AI Code Typer?

An interactive web application that helps developers **improve typing speed and accuracy** through:

- 🤖 **AI-generated code snippets** (Python, JavaScript, C++, Java, and more)
- 📊 **Gamified progress tracking** with levels, badges, and achievements
- ☁️ **Cloud sync** across all your devices
- 🎹 **Realistic keyboard sounds** (Cherry MX Blue, Brown, Topre)

## ⚙️ Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/naseem2917/ai-code-typer.git
cd ai-code-typer

# Install dependencies
npm install

# Start development server
npm run dev
```

> **🔒 Note:** No API key configuration needed locally. The app uses a secure Cloudflare Worker proxy for AI generation.

## 🏗️ Architecture

```
┌─────────────────────────────────────────────────────────┐
│                       Frontend                          │
│              React + TypeScript + Vite                  │
└─────────────────────────────────────────────────────────┘
                  │                         │
                  ▼                         ▼
        ┌─────────────────────┐  ┌────────────────────┐
        │  Cloudflare Worker  │  │     Firebase       │
        │     (AI Proxy)      │  │  Auth + Firestore  │
        └─────────────────────┘  └────────────────────┘
                  │
                  ▼
        ┌─────────────────────┐
        │   Google Gemini AI  │
        │     (v1beta API)    │
        └─────────────────────┘
```

### Security
- ✅ Gemini API key hidden in serverless proxy
- ✅ Firebase security rules protect user data
- ✅ No secrets exposed to client
